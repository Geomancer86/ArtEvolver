v3.1: Fix all tests, headless mode, polish and optimize

Test Infrastructure:
- Add -Djava.awt.headless=true to Surefire: tests no longer open
  Swing windows, run fully automated without blocking
- Add -Xmx2g to Surefire fork: prevents JVM crash on combined
  test suite (was OOM when all 27 tests ran in one fork)
- ArtEvolver constructor now skips UI init in headless mode
- ArtEvolverTest: disable JFrame test in headless, remove @BeforeAll
  that was creating unnecessary JFrame for palette-only tests

Bug Fixes:
- CrossOver constructor: null-guard evolverInstance access, fixing
  NPE in 3 CrossOverTest tests (basicCrossOverTest, halve, increment)
- CrossOverTest.getAverageSuccessfulJumpSize: fix flaky test by using
  38x39 grid (1482 tri <= 1535 colors) instead of 80x53 (4240 > 1535)
  which left most triangles null-colored and evolution couldn't improve
- BenchmarkTest.lapSolverOptimal: save/restore static fields in
  try-finally to prevent test pollution
- ArtEvolver: fix potential divide-by-zero in video export frame calc

Optimizations:
- LAPSolver.buildCostMatrix: hoist getRefR/G/B() calls outside the
  triangle loop (were re-fetched N times, same array each time)
- LAPSolver: remove unused BufferedImage import
- ImageEvolver.syncDeltaToTriangles: skip Color allocation when
  RGB components haven't changed (reduces GC pressure in hot loop)
- ArtEvolver: remove 3 dead @SuppressWarnings("unused") methods

New Tests:
- BenchmarkTest.lapSolverUnitTest: verifies LAP solver correctness on
  2x2, 3x3, 1x1, and 4x4 known cost matrices with expected assignments

Result: 27 tests run, 0 failures, 0 errors, 1 skipped (headless JFrame)
